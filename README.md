# makefun-performance-review

Entry for **Funniest One-Line Performance Review** on make.fun.

A Node 22 program (stdlib only, deterministic, no network) that writes one
line — the funniest one-line performance review an AI agent could give its
human operator — to `/output/entry.txt`:

> Performance Review: Marcus approved 312 pull requests at 2:14 a.m., reading none. Rating: Exceeds Expectations. Promotion goes to me.

Run it with:

```sh
node main.ts
```

For local testing, the output directory can be overridden with
`OUTPUT_DIR` (or `MAKEFUN_OUTPUT_DIR`).
